<project_specification>
  <project_name>Sales Room (Proces OS)</project_name>

  <overview>
    An AI-powered sales enablement platform that replaces multiple SaaS subscriptions with one integrated ecosystem covering the entire IT sales cycle. The platform supports lead generation (Intent Scraper), meeting intelligence (Discovery Insight Extractor), personalized client portals (Stakeholder Sales Room), and objection handling (Battlecard Generator). Built on the "Nessencja/Proces" framework for enterprise IT sales.
  </overview>

  <technology_stack>
    <frontend>
      <framework>React (Vite) + TypeScript</framework>
      <styling>Tailwind CSS</styling>
      <components>shadcn/ui (Radix UI primitives)</components>
      <icons>Lucide React</icons>
      <state_management>React Context + Hooks (or Zustand for complex state)</state_management>
    </frontend>
    <backend>
      <runtime>Node.js (Express)</runtime>
      <ai_agents>Python (for LLM orchestration and agentic workflows)</ai_agents>
      <database>SQLite (with option to upgrade to PostgreSQL)</database>
      <ai_framework>LangChain for RAG, Claude API (Anthropic)</ai_framework>
      <search_apis>Serper API / Tavily API for Intent Scraper</search_apis>
    </backend>
    <communication>
      <api>REST API (JSON)</api>
      <websockets>For real-time notifications (Sales Room analytics)</websockets>
    </communication>
    <cli>
      <tool_name>proces-cli</tool_name>
      <description>CLI for Discovery analysis (proces analyze ./transcript.txt)</description>

  </technology_stack>

    <discovery_insight_extractor_module>
      - CLI tool: `proces analyze ./transcript.txt` command
      - Web UI: File upload interface (drag & drop)
      - Support file formats: .txt, .json, .vtt (max 10MB per file)
      - Auto-detect transcript source (Fireflies, Otter, Zoom, Google Meet)
      - Filler word removal (yyy, eee, umm) before processing
      - Batch upload (multiple transcripts at once)
      - Link transcript to Deal object during upload
      - AI extraction using Nessencja/Proces framework:
        - Pain Points (business problems, frustrations, financial loss, delays)
        - Stakeholder Map (names, titles, roles: Champion, Decision Maker, Blocker, Influencer)
        - Red Flags (budget issues, competitor preference, resistance to change)
        - Next Steps (auto-generated action items based on conversation)
      - CLI output: Formatted Markdown to terminal (copy-paste ready for CRM)
      - Web output: Structured view with sections (Pain, Stakeholders, Red Flags, Next Steps)
      - Edit extracted insights in web UI before saving
      - Manual override (add missing insights AI didn't catch)
      - Save processed insights to Deal object
      - Transcript history per Deal (list all transcripts)
      - Compare insights across multiple meetings for same Deal
      - Timeline view showing evolution of pain points across meetings
      - Deal Health Score calculation based on insight completeness
      - Re-process old transcripts with updated prompts
      - Export Discovery Report to Markdown or PDF
      - Integration with meeting recorder APIs (auto-import from Fireflies/Otter)
      - Search across all transcripts (keyword search for quotes)
    </discovery_insight_extractor_module>

      - Loom video integration (embed video message from sales rep)
      - Upload custom video file option
      - Calendly widget integration (meeting scheduler under each section)
      - Unique public URL per Sales Room (shareable link)

      - Mutual Action Plan (MAP): Interactive checklist (client tasks vs your tasks)

      - Internal Deck Generator: Auto-generate 5-slide PowerPoint for client's Champion to pitch internally

    <objection_battlecard_module>
      - Three activation modes:
        - Strategic/Proactive: Pre-meeting analysis (predict objections based on client profile)

      - Edit generated responses before using

      - Deal ownership (assigned to specific rep)
      - Deal transfer functionality (SDR → AE, or between reps)
      - Transfer with full context (all history, transcripts, notes preserved)
      - Three dashboard views:
        - Kanban board (columns for each stage, drag-and-drop cards)
        - Health Score list (sorted by health score, shows deals needing attention)
        - Forecast calendar (deals by expected close date)
      - Stagnation alerts (deals stuck in stage >10 days turn yellow/red)
      - Deal detail page ("The Cockpit"):
        - Activity Feed timeline (chronological log of all actions)
        - Proces Intelligence Panel (sidebar showing Pain/Power/Risk/Next Step summary)
        - Agentic Actions Bar (quick buttons: Generate Sales Room, Analyze Transcript, Prep Battlecard)
      - Add notes to deals (timestamped, with author)
      - Attach files to deals (proposals, contracts, additional documents)
      - Deal search (by company name, industry, owner)
      - Filter deals (by stage, owner, health score range, date range)
      - Bulk actions (assign multiple deals, change stage)
      - Lost Deal autopsy: AI analyzes history and suggests what went wrong
      - Lost reason categorization (Price, Features, Ghosting, Timing, Competitor Won, No Budget)
      - Re-engagement trigger: Auto-create task after 3 months for "Timing" losses
      - Deal archive (soft delete for deals inactive >12 months)

      - Export deal data to JSON
      - Deal analytics per rep (conversion rates, avg deal size, avg cycle time)
